# 🚀 Ellen Ochoa: Space Science Adventure

An educational 2D browser game about **Dr. Ellen Ochoa**, an engineer, astronaut, scientist, and former director of NASA's Johnson Space Center.

The game combines space exploration with facts about Ochoa's biography, education, scientific research, inventions, NASA missions, and impact on science and society.

## 🎮 Play the Game

Move the astronaut around the screen and collect the yellow **?** knowledge orbs.

### Controls

| Key       | Action     |
| --------- | ---------- |
| `W` / `↑` | Move up    |
| `A` / `←` | Move left  |
| `S` / `↓` | Move down  |
| `D` / `→` | Move right |

### 🎯 Objective

* Collect knowledge orbs.
* Learn facts about Ellen Ochoa.
* Avoid space debris.
* Earn points.
* Collect all 10 knowledge items to complete the mission.

This game was created as an educational project to make learning about a scientist more interactive.

## 👩‍🚀 About Ellen Ochoa

Dr. Ellen Ochoa is an American engineer, scientist, and former NASA astronaut.

She became the **first Latina woman to travel into space** when she flew aboard Space Shuttle Discovery in 1993.

Her career includes work in optics, electrical engineering, image processing, spaceflight, and NASA leadership.
